# Kapten Planka

Romans 3 med **Kapten Rötägg**. Romans 25 med **Kapten Blåskägg**: hon krossade hans hjärta för att ta en annan kaptens skuta och besättning. Rötägg vet inte om Blåskägg. Fuling vet inte om Planka. Fiende 5 mot **Kapten Fuling** (oljan vid förra kaptensskålen: Fuling kastade sig på **Kapten Rosing**, Rosing skrattade. Inte att Planka också tar Blåskägg: Fuling vet inte om romans 25).
